Privacy Policy

for gws, a personal command-line tool

Last updated: 29 August 2026

What this application is

gws is a command-line program written and used by John (Jack) Kelliher to read and manage his own Google account data, principally Gmail, from his own computer. It is a personal tool. It has no other users, no public sign-up, no web interface, and no server component. It is not offered to anyone else, commercially or otherwise.

What data it accesses

When authorised, gws uses the Gmail API to read, compose, label and send mail in the single Google account of its author. It accesses no other person's account, because no other person uses it.

What is collected

Nothing. Specifically:

  • No data is collected or retained by the developer beyond the author's own machine.
  • No data is transmitted to any third-party server. The only network connection the tool makes for this purpose is directly to Google's own APIs.
  • No data is shared with, sold to, or disclosed to any third party.
  • No analytics, telemetry, tracking or advertising of any kind.
  • No data is used to train any model.

Message content fetched from the API is displayed in the author's terminal and cached locally on the author's own computer so the tool does not have to re-fetch it. That cache never leaves the machine.

Credentials and tokens

OAuth credentials and refresh tokens are stored locally on the author's own computer, in the operating system keyring where one is available, and otherwise in an encrypted file in the author's own configuration directory, readable only by his user account. They are never transmitted anywhere except to Google in order to authenticate. Access can be revoked at any time from the author's own Google Account permissions page, which immediately and permanently ends the tool's access.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

Because no data is held anywhere but the author's own computer, there is nothing held on anyone else's behalf to retain or delete. The author can erase the local cache and stored tokens at any time by deleting them from his machine.

Children

This is a single-user personal tool and is not directed at anyone, including children.

Changes to this policy

If this tool's behaviour changes, this page will be updated and the date above revised.
